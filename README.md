# ☕ Coffee Machine (Java)

A simple console-based coffee machine program written in Java.
This project simulates a real coffee machine where users can buy drinks, refill resources, take money, and clean the machine.

---

## 📷 Example Output

```
Write action (buy, fill, take, clean, remaining, exit):
buy
What do you want to buy? 1 - espresso, 2 - latte, 3 - cappuccino:
1
I have enough resources, making you a coffee!
```
